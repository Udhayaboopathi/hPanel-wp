Migrate a WordPress Website

RK Host does not run a one-click importer — migrations use the same verified tools as everything else in the panel, so nothing is silently half-copied. Follow these steps; each one is a real, working feature.

Step 1 — Create the new website

Create an empty WordPress site on the target domain with the Create Website wizard and let provisioning finish. This gives the migrated site its own container, database and restricted database user.

Step 2 — Bring the files over

Upload the old site's wp-content (uploads, themes, plugins) into the new site with the File Manager. For a site that already exists in RK Host, pick it here:

Step 3 — Import the database

Export the old database as .sql or .sql.gz, then import it from the new site's Database page. The import runs inside the site's own database — other sites are not touched.

After importing, update the site URL inside WordPress (Settings → General) or with the WordPress tab's WP-CLI tools if the domain changed, and flush permalinks once.

Step 4 — Verify, then point DNS

Open the site, check pages, forms and media, then point the domain's DNS A records at this server (the exact records are shown on the site's Domains & SSL page). Keep the old hosting live until DNS has propagated.

Moving between RK Host servers?

Use the same steps above: export the database from the source site's Database page, copy the files with the File Manager, and import both into the new site here. Restoring a backup archive taken on a different RK Host server is not supported yet — backups are tied to the site that created them. This limitation is tracked in RK-HOST-REMAINING-ISSUES.md.
